# Pizza Menu Assignment

This project is a fully functional Pizza Menu application that allows users to view, customize, and order pizzas. The app is developed using HTML, CSS, and JavaScript and includes detailed comments throughout the JavaScript file for clarity.

---

## Features
- **Pizza Menu Display**:
  - A list of available pizzas, each with a description, price, and image.
- **Customization Options**:
  - Users can customize their pizza by selecting toppings, sizes, and crust types.
- **Dynamic Price Calculation**:
  - The app dynamically calculates the total price based on user selections.
- **Order Summary**:
  - Displays a summary of the user's order, including selected pizza, customizations, and total cost.
- **Reset/Place Order**:
  - Allows users to reset the order form or place their order.


---

## Features
- **Interactive Gameplay**: 
  - Two players can take turns clicking on cells to place their marks (`X` and `O`).
  - The game board updates dynamically based on player actions.
- **Win Condition Detection**:
  - The game identifies when a player has won by completing a row, column, or diagonal.
  - Displays a message announcing the winner.
- **Draw Detection**:
  - If all cells are filled and no winner is detected, the game announces a draw.
